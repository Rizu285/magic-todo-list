# Magic To-Do List 📝

A simple command-line To-Do List application built with Python. This project allows users to add tasks, view their tasks, and manage a basic to-do list through an interactive menu.

## 📌 Features

* Add new tasks
* View all saved tasks
* Simple and user-friendly interface
* Input validation for empty tasks
* Lightweight and easy to run

## 🛠️ Technologies Used

* Python 3


## 🚀 Getting Started

### Prerequisites

Make sure Python 3 is installed on your system.

Check your Python version:

```bash
python --version
```

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Rizu285/magic-todo-list.git
```

2. Navigate to the project folder:

```bash
cd magic-todo-list
```

3. Run the application:

```bash
python todo.py
```

## 💻 Usage

When you run the program, you will see a menu:

```text
Welcome to the Magic To-Do List!

What would you like to do?
1. Add a task
2. View all tasks
3. Quit
```

### Example

```text
Enter your choice (1/2/3): 1
Enter your task: Complete Python Assignment

Task added: 'Complete Python Assignment'
```

To view tasks:

```text
Your To-Do List:
1. Complete Python Assignment
```
